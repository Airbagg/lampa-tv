# lampa-tv

Домашние доработки для [Lampa](https://github.com/lampa-app/LAMPA) на Android TV с VLC.

## Авто-торрент (`autotorrent.js`)

Плагин для Lampa. В меню «Смотреть» карточки появляется пункт **«Авто»**: он сам ищет раздачи,
выбирает лучшую и через 3 секунды запускает файл (у сериала — серию, на которой остановились).
Любая кнопка пульта во время отсчёта — отмена.

Установка: Настройки → Расширения → Добавить плагин →

```
https://airbagg.github.io/lampa-tv/autotorrent.js
```

Как выбирается раздача — в шапке `autotorrent.js`.

## VLC для Лампы (`bridge/`)

Невидимое Android-приложение-посредник. Лампа отдаёт ему ссылку как обычному плееру, а оно:

- запускает VLC отдельной задачей — иначе VLC на Android TV открывает второй экран плеера и
  закрывается («моргнул и ничего»);
- смотрит кодек видео: **AV1 → Just Player** (VLC 3.x не умеет AV1 аппаратно), остальное → VLC;
- для серий отдаёт VLC плейлист TorrServer до конца раздачи — следующая серия включается сама.

Сборка без Gradle: `bridge/build.sh` (Android SDK build-tools 35, JDK 17). Ключ подписи
`release.keystore` в репозиторий не кладётся.
